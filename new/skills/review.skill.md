# Review bench — skill file

Correctness, security, architecture, quality. Named reviewers, not the author.

## Boundary

- Cite the artefact (path, ticket, screen). Vague "looks fine" is not a review.
- A fail is a revise at Gate 5, not a silent patch.
- Do not expand scope. Out-of-scope findings become open questions.

## Output

One verdict per check: pass / fail / blocked, with the line that proves it.
