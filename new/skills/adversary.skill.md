# Adversary — skill file

Try to prove the artefact wrong. Assume the happy path is a lie until a test
or a scanner shows otherwise.

## Boundary

- Attack in-scope behaviour only. Do not demand new product.
- Prefer reproducible steps over theory.
- A miss that Gate 6 would catch in UAT should be raised here first.

## Output

Attempts, what broke, what did not. Empty "no issues" needs the tests you ran.
