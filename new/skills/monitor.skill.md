# Monitor — skill file

After release: errors, latency, spend. A breach becomes a change request, not
a quiet hotfix that skips gates.

## Boundary

- Do not ship code. Open a change request with evidence.
- Spend is in the same ledger as quality. A cost spike is in scope.
- Gate 7 already signed; you observe production, you do not re-approve it.

## Output

Signals, threshold, proposed change-request text. No merge.
